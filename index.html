Shared database setup

Required for shared access

A local HTML file alone cannot share live data between different phones/computers. Connect this page to one shared Supabase database. Everyone must open the same hosted page or their copy configured with the same project details.

The project URL and public anon key are saved in this browser. Never paste a service-role key here.

Database setup instructions (one-time)

In Supabase, open SQL Editor, paste and run this SQL. This simple setup allows anyone with the project details to read and change stock data. Use only for a trusted group; for stronger privacy, add user sign-in and access policies before sharing.

create table if not exists public.furniture_stock (
  id bigint generated by default as identity primary key,
  entry_date date not null,
  product_name text not null,
  quantity integer not null default 0,
  consume_date date,
  consumed_quantity integer not null default 0,
  created_at timestamptz not null default now()
);

alter table public.furniture_stock enable row level security;

create policy "Allow shared stock access"
on public.furniture_stock for all
to anon
using (true)
with check (
  quantity >= 0
  and consumed_quantity >= 0
  and consumed_quantity <= quantity
);

alter publication supabase_realtime add table public.furniture_stock;

If the realtime publication command says the table is already included, you can ignore that message. In Supabase Table Editor, confirm the table is named furniture_stock.
